# Customer Hub Suite

Crie a estrutura inicial de um sistema Web de Gestão de Clientes (SaaS mínimo) usando Node.js (Express) no backend e React (ou HTML/Tailwind) no frontend. Configure um banco de dados SQLite (ou PostgreSQL) com tabelas para: Usuários (id, nome, email, senha, perfil ['admin' ou 'comum']) e Clientes (id, nome, cpf_cnpj, email, telefone, endereco, usuario_id).
